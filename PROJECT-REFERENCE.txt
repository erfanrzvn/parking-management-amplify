1️⃣ ParkingConfig

   ─────────
   - id: string (PK)
   - email: email
   - name: string
   - phone: string
   - building: string
   - floor: string
   - unitNumber: string
   - plate: string
   - residentCode: string
   - userId: string
   - householdId: string (برای گروه‌بندی خانوارها)

3️⃣ Reservation
   ───────────
   - id: string (PK)
   - residentId: string
   - residentCode: string
   - residentFloor: string
   - residentPlate: string
   - guestPlate: string
   - guestMobile: phone
   - guestEmail: email
   - startTime: datetime
   - endTime: datetime
   - status: string (CANCELLED)
   - deletedAt: datetime (soft delete)
   - createdAt: datetime

   Authorization:
   ✅ Public: full access (برای guest booking)
   ✅ Admin: full access

================================================================================
                        🔧 عملیات CRUD - چطور کار میکنه
================================================================================

CREATE RESIDENT:
1. Frontend: createResident() در graphql.ts
2. AppSync: mutation CreateResident
3. DynamoDB: Insert به جدول Resident
4. Frontend: reload data و نمایش

DELETE RESIDENT (Soft Delete):
1. Frontend: deleteResident() در graphql.ts
2. AppSync: mutation UpdateResident با deletedAt=now
3. DynamoDB: Update رکورد (NOT physically deleted!)
4. Frontend: فیلتر کردن رکوردهای deletedAt != null

CANCEL RESERVATION:
1. Frontend: cancelReservation() در graphql.ts
2. AppSync: mutation UpdateReservation
3. DynamoDB: Update با status='CANCELLED', deletedAt=now
4. Frontend: reload و نمایش

                        🐛 مشکلات رایج و راه حل
================================================================================

❌ Error: "Unauthorized" (401)
   → API Key اشتباه یا منقضی شده
   → چک کن: amplify_outputs.json → api_key
   → چک کن: aws appsync list-api-keys --api-id b7rjz6vdtjauzlzqztpuiylhce

❌ Error: "Field 'listReservations' undefined"
   → Query name اشتباه است
   → Schema رو چک کن: amplify/data/resource.ts

❌ Delete کار نمیکنه
   → Resolver نداره یا API ID اشتباهه
   → از updateReservation استفاده کن بجای custom mutation

❌ Build Failed
   → Backend deployment فعال بوده
   → amplify.yml رو چک کن - backend باید comment باشه

❌ داده‌ها نمایش نمیشن
   → API key یا URL اشتباه
   → Browser console رو چک کن
   → Network tab رو چک کن (401 یا 403؟)
